# Santtun Ray — Premium React Portfolio

A responsive, futuristic developer portfolio built with React, Vite, Tailwind CSS, Framer Motion, Three.js / React Three Fiber and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Customize

- `src/main.jsx` — resume-backed profile content, projects, experience, achievements and links.
- `src/styles.css` — responsive visual system, glass cards, grid background and breakpoints.
- `public/Santtun-Ray-Resume.pdf` — supplied resume PDF used by the View/Download Resume buttons.

### Notes
- Project GitHub links currently point to the supplied GitHub profile because individual repository URLs were not provided in the source material.
- Live demo buttons are placeholders (`#`) until real deployment URLs are supplied.
- The contact form demonstrates validation/loading/success UI without requiring a backend. Replace the `submit` handler with your API endpoint or a `mailto:` integration when deploying.
